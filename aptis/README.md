# Plan de Estudio Diario (1 hora) para Aptis Advanced en 4 Meses

Basado en la estructura del **Aptis Advanced Guide for Teachers (May 2025)**, he diseñado un plan progresivo que cubre los cinco componentes del examen: **Core (Grammar & Vocabulary), Reading, Listening, Writing y Speaking**.

---

# Estructura General del Examen (según el PDF)

| Componente | Tiempo | Partes |
|---|---|---|
| **Core** (Grammar & Vocabulary) | 25 min | 2 partes (25 preguntas c/u) |
| **Reading** | 60 min | 4 partes |
| **Listening** | 30 min | 4 partes |
| **Writing** | 45 min | 3 partes |
| **Speaking** | ~12 min | 4 partes |

**Nivel objetivo:** B1–C2 (Aptis Advanced)

**Estrategias clave (según el PDF):**
- **Reading:** Leer todo el texto antes de responder; buscar pistas (palabras similares, ideas, temas).
- **Listening:** Usar la doble reproducción en Parts 1–2; en Parts 3–4 solo se escucha una vez.
- **Writing:** Mantener el conteo de palabras; evitar lenguaje de redes sociales; usar registro formal.
- **Speaking:** No quedarse corto; usar todo el tiempo; evitar listas de oraciones simples.

## 🎯 Consejos Clave del PDF

1. **Core:** Usar el British Council / EAQUALS Core Inventory para saber qué gramática se evalúa.
2. **Reading:** Practicar con artículos de revistas; identificar la idea principal de cada párrafo.
3. **Listening:** Aprovechar la doble escucha en Parts 1–2; leer preguntas antes de escuchar.
4. **Writing:** Evitar errores comunes: no responder la pregunta, escribir demasiado con mala gramática, no usar variedad de estructuras.
5. **Speaking:** Hacer sound check; hablar claro; no usar solo "and" y "so"; usar variedad de estructuras.
6. **Aptis for all:** Si tienes necesidades especiales, contacta al centro para adaptaciones.
